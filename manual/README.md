# Ручные пояснения (manual/)

Одна страница = один файл `<slug>.json`. Сайт публикует их по адресу `/x/<slug>`.
Автоматика (trend_site.py) эти страницы не переписывает; при совпадении slug ручная страница главнее.

Поля:
- `subject` — о ком/о чём (имя, термин)
- `kind` — person | event | term | law | product | organization | other
- `query` — точная фраза, которую вводят в Google
- `title` — заголовок, содержит `query` (до ~70 символов)
- `answer` — прямой ответ, 40–60 слов
- `body` — 1–3 абзаца новых фактов, абзацы через `\n\n`
- `in_the_news` — 1–2 предложения: почему это в новостях сейчас
- `faq` — список `{"q": "...", "a": "..."}`
- `links` — список `["Издание", "Заголовок", "https://..."]`
- `made` — дата первой публикации (ISO, UTC); `updated` — дата правки (новое значение = повторный пинг IndexNow)
- `news` — true для НОВОСТИ (свежее событие дня). Новости показываются наверху главной с меткой News и закрыты от Google (noindex): это пересказ событий для читателей, а не страница для поиска.
- `image_wiki` — ТОЧНОЕ название статьи английской Википедии (например "Coachella Valley Music and Arts Festival"), чьё главное фото подходит к странице. Сайт сам скачает его, только если на Wikimedia Commons оно под свободной лицензией (CC / public domain), и подпишет автора. Никаких других картинок не добавлять (чужие фото с сайтов нельзя). Если подходящей статьи с фото нет — поле не ставить.
