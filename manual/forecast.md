# Прогноз запросов (А + Б → С)

А = что гуглили (Trends CSV, Search Console). Б = почему (статьи). С = что будут гуглить.
Закономерности из Trends 30 окт – 5 нояб 2026:
- Человек в новостях → «who is X», «X wife / married», «how old is X», «where is X from», «is X democrat or republican», «X now» (старая звезда снова на виду).
- Незнакомое слово в речи/репортаже → «what does X mean» (habibi 100K+, incumbent 50K, aipac 50K).
- Происшествие → техническая вещь из него: рабдомиолиз (500K, бегун умер на марафоне), Learjet (крушение), olmesartan (отзыв лекарства).
- Травма спортсмена → «what happened to X», «X injury update».
- Документалка / сериал по реальным событиям → «what happened to X», «is X a true story», старое дело (Netflix → Натали Холлоуэй).
- Игра / шоу → «release date», «launch time», «server status».
- Магазины / госвыплаты → «X menu», «red cup day», «closing list», «payment schedule».
- Близкие выборы → «why are results taking so long», «did X win», правила подсчёта.
- Неделя наград MLB (9–12 нояб) → «how is X voted», «what is X award», критерии (rookie eligibility); новая награда = мало конкурентов.
- Люди пишут слитные термины с пробелом/дефисом: «tele rally», «tele-rally», «telly rally» — в FAQ давать варианты написания.
- Смена большинства в Конгрессе → процедурные вопросы: «when does the new congress take office», «how is the speaker elected», «lame duck session».
- Игрок из Японии/Кореи выставлен на постинг → «who is X» + «posting system» (окно 45 дней, дедлайн).
- Сериал по реальному делу → люди ищут по ИМЕНИ реального человека («darryl mccauley where is he now»), а не по названию шоу; Netflix-название в подсказках может отличаться («bank under siege»).
- Документалка Netflix о реальном человеке дала больше всего трафика сайта за всё время (dane-cook-brother: 2485 показов и 17 кликов за 7 нояб). Пик — на 2-й день после выхода. Это главный рычаг: искать доки/сериалы «о реальных людях» и писать за 1–5 дней.
- Термины MLB (награды, non-tender, DFA): показы малые (5–50 в день), поз. 5–20 — ниша с небольшим объёмом; писать только когда нет кино/доков.
- Победитель/финалист сразу двух наград → исторический вопрос «has anyone ever won both» (rookie + Cy Young), «who has the most X».
- Всплески «X meaning / slang» сразу по нескольким странным словам (carat, charred, korn, leak; loafy, roamy) — это разгадки NYT Connections/словесных игр, а не сленг. Не писать.
- Вопросы про небо «bright star in the east this morning» растут, когда яркая планета (Венера) возвращается на утреннее небо — сезонный термин.
